# 七禧商城用户端

`app-mp/` 根目录是唯一的 **uni-app x** 工程，使用 HBuilderX 5.0+ 打开后，分别选择“运行到浏览器”和“运行到微信开发者工具”。两种目标使用同一份 `pages.json`、`.uvue` 页面与 `.uts` 逻辑。

本目录只承载 H5 与小程序；iOS、Android、鸿蒙分别由 `app-ios/`、`app-adnroid/`、`app-harmony/` 独立实现，但与本目录共享 C 端接口、JWT 与功能验收基线。

不得再用 `npm run dev:h5` 或标准 uni-app CLI 启动 `src/`：该目录仅保留为旧版业务页面迁移参考，不是运行或发布入口。页面迁移完成前，不允许将旧版 `src/` 构建产物发布。

当前已迁移的基础页面：首页、分类、商品列表、商品详情、店铺主页、购物车、我的、登录、收货地址、普通订单核对/创建/支付/列表/详情、优惠券领取/查询/计价、积分商品兑换（独立积分订单）、秒杀活动展示、拼团查询/开团/参团（独立活动订单）、预售首付款与定金尾款（独立支付状态）、好友助力/助力单/助力价下单（独立活动订单）、预约服务/日期时段选择/核销订单、直播间与挂载商品、社区内容列表与话题筛选、分销中心（绑定上级/佣金流水）、平台公告、用户协议、售后申请/列表/详情，以及从商品、店铺发起的商户客服。

客服使用仓库内 `uni_modules/pte-im-sdk` 和 `uni_modules/pte-im-uikit`（来源为共享 `pte-live-im-sdk` 的原样模块）。C 端先创建 `/cs/threads` 业务会话，再取得短期 UserSig 启动 SDK；文本由 SDK E2EE 通道发送，UserSig 只在内存中使用，禁止写入 storage、日志或源码。运行环境必须在 `im.api_public_url` 与 `im.ws_public_url` 配置客户端实际可访问的地址。

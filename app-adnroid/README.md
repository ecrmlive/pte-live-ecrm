# app-adnroid — 七禧 Android 客户端

本目录名称按项目约定固定为 `app-adnroid`。独立 Android 工程目标为 Android 12 / API 31+、Kotlin、Jetpack Compose（兼容 View）、MVVM/Clean Architecture；不得以 `app-mp` WebView 替代。

与 `app-web`、`app-mp`、`app-ios`、`app-harmony` 共用 `api-business` 的 C 端业务契约和 JWT；用户登录来源标识为 `android`。导航栏高度 44px，紧贴状态栏底部。

当前仅完成目录收敛，尚未创建 Gradle 工程或宣称功能完成。

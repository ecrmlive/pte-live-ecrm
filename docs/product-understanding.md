# 产品与业务全景

七禧 CRM 是多商户入驻商城：统一后台管理平台规则与运营，店铺系统负责经营与履约，用户在 PC、小程序和 H5 完成交易。系统边界、JWT 与数据库以前置 [SYSTEM-ARCHITECTURE.md](./SYSTEM-ARCHITECTURE.md) 为准。

## 系统与角色

| 系统 | 角色 | 核心职责 |
| --- | --- | --- |
| 统一后台 `/admin/` | 平台、商户、区域、客服、运营 | 商户审核、全局监管、区域管理、内容/营销、客服辅助、配置与审计 |
| 店铺系统 `/merchant/` | 店铺主账号、店员、配送、服务人员 | 商品、库存、订单履约、店铺营销、物流、装修和店铺财务 |
| PC / 小程序 / H5 / iOS / Android / 鸿蒙 | C 端用户 | 浏览、加购、支付、售后、会员、分销、客服 |

## 数据归属

- `qixi_crm_admin.qixi_crm_a_*`：后台身份、RBAC、数据范围、区域和运营配置。
- `qixi_crm_business.qixi_crm_b_*`：用户身份绑定、购物车、交易、支付、售后、营销、资产与业务审计。
- `qixi_crm_merchant.qixi_crm_m_*`：店铺、员工、商品经营、库存、履约、物流、装修和店铺操作记录。
- `pte_im_a_*` / `pte_im_*`：只由 pte-live-im 管理 IM。

## 主链路

```text
商户申请 → 统一后台审核 → 创建店铺与店铺账号
→ 店铺维护商品/SKU/库存 → 发布消费视图
→ C 端加购并按店铺拆单 → 支付 → 订单履约/核销
→ 售后状态机 → 商户结算、用户资产与审计
```

高风险域（支付回调、退款、库存、优惠、积分、佣金、结算）只在所属数据库内完成事务与幂等；跨库通过事件和稳定 ID 协作。

## 客服与 IM

客服角色在统一后台工作，通过 pte-live-im 与 pte-live-im-sdk 收发消息。七禧仅保存订单、店铺授权和会话业务索引，禁止保存 IM 消息正文或自建 IM 协议。

## 验收

CRMEB 功能以 [功能验收总清单](./CRMEB-FULL-FUNCTION-CHECKLIST.md) 逐项实现；下单、支付、退款等状态机以 [FUNCTIONAL-TRUTH.md](./api/FUNCTIONAL-TRUTH.md) 对照，但其中旧表名仅为参考源码语义，不是七禧新表设计。

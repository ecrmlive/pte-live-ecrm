# C 端图标 / 图片素材清单（Figma 设计用）

> 用途：丢给 Figma 出图。表内 **尺寸 = 建议设计/导出像素（上传稿）**。  
> 设计基准：移动端 **750 宽**；导出 PNG（必要时 @2x / @3x 另议）。  
> 本仓 DIY 以 `admin-platform` 文案为准；CRMEB 仅作对齐参考。

---

## 0. 出图总原则

| 类型 | 设计尺寸 | 风格建议 | 运行时大致显示 |
|---|---|---|---|
| 首页彩色快捷入口 | **88×88**（可按 CRMEB 出 90×90） | 圆形彩色填充 | ≈42–45px |
| 「我的服务」宫格 | **52×52** | 线框 / 扁平单色或浅底 | ≈26px |
| 订单状态五态 | **100×100** | 线框（可红描边） | ≈24px 或 DIY 位图缩放 |
| 详情顶栏/弹层/底栏 | **40×40**（线框；也可 32×32） | 线性 icon | 显示约 16–20px |
| DIY 金刚区通用 | **88×88** | 同首页入口 | ≈42px |
| 悬浮客服 | **90×90** | 圆形 | 展示 44×44 |
| 悬浮球 | **120×120** | 圆形 | 展示 44×44 |
| 公告/标题小图标 | **32×32** | 线性或色块 | — |
| 分享 Logo | **80×80** | 方/圆均可 | — |
| Tab 底栏 | **81×81** | 未选中灰 / 选中主题色 | CRMEB 参考 |

源稿可先做更大再压：首页彩图常见源文件 **135×135** → 导出 88/90。

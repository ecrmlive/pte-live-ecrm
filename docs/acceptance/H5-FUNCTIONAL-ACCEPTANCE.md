# H5 功能验收台账

> 范围：`app-uni/` 的 H5 构建，与微信小程序共用页面和 C 端 API；基线为
> `docs/features/03-user-app.md` 的 342 个操作。此台账只记录有实现、测试和数据证据的项目，
> 未列入的功能不得视为完成。

## 模拟数据

- 入口：`sql/business/05_test_data.sql`，执行前已声明 `SET NAMES utf8mb4`。
- 数据仅限本地/测试：中文店铺、商品、营销、DIY、直播、社区与客服坐席投影，以及明确标记的演示消费者；
  不包含真实手机号、支付凭据、证书或个人身份信息。
- 订单、支付回调和库存扣减不以 SQL 伪造成功；必须由 API 状态机与回调/测试驱动。

## 本轮验收场景

1. 未登录访问“我的”显示登录入口；登录后读取当前用户昵称与手机号。
2. 在结算页进入地址列表，选择非默认地址后返回结算页，订单创建只提交所选地址 ID。
3. 地址仅能读取、编辑或删除当前 JWT 用户自己的记录；非法地址 ID 返回 400。
4. 地址夹具与响应字段保持 UTF-8 中文可读，不能将姓名、地址写入日志。
5. 登录用户在商品详情页可查看收藏状态、收藏或取消收藏；“我的收藏”可查看并取消商品/店铺收藏。
6. 积分兑换、拼团、预售、预约、助力下单均优先使用用户在地址选择页确认的地址 ID；地址不存在或不归属当前用户时由 API 拒绝创建。
7. 售后列表与详情优先按 API 的 `status_code` 展示；仅 `applied`、`merchant_handling` 显示取消或申请平台介入，退款处理中不显示误导操作。
8. 登录用户打开商品详情后写入自己的浏览记录；可在“浏览记录”中查看、删除单条或清空全部，接口按 JWT 用户隔离。
9. 商品列表的销量、价格筛选会传递受服务端白名单保护的 `sort` 与 `order` 参数；同一筛选再次点击切换升降序。
10. 未支付主单仅在 `pay_status=pending` 时显示“去付款 / 取消订单”；取消由服务端订单状态机执行，已关闭订单显示“已取消”。
11. 用户可提交中文反馈并查看自己的处理状态与回复；服务端通过 JWT 用户 ID 隔离反馈详情。
12. 仅订单归属用户且订单状态为 `completed` 的订单项可提交一次 1–5 星中文评价；新评价待审核，不能伪造已发布展示。
13. 用户维护个人或企业开票抬头；企业抬头必须填写税号。仅当前用户的已支付、未进入售后的订单可提交一次发票申请，申请时写入抬头快照。
14. 登录用户在“我的”进入商户入驻，上传营业执照后可提交中文申请；页面仅展示自己的申请记录，进入详情后可查看审核状态与审核说明。
15. 登录用户可在“我的积分”查看积分余额、累计获得/使用与自己的积分流水；积分商城继续独立承担兑换下单。
16. 登录用户可在“会员中心”查看当前等级、可用等级和只属于自己的成长记录；前端不根据演示数据推断或开通付费权益。

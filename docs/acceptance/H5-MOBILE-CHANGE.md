# H5 手机号换绑验收记录

日期：2026-08-04

## 功能闭环

- 已绑定手机号页面提供“更换手机号”入口，未绑定用户仍走原有首次绑定流程。
- 换绑页先验证当前手机号，再验证新手机号；每次发送均必须通过一次图形安全验证。
- 两条短信验证码都绑定 `change_mobile` 用途，只保存 SHA-256 摘要，五分钟过期且只能消费一次。
- `POST /api/app/v1/auth/mobile/change` 仅注册在认证路由组，客户端必须同时提交旧手机号及验证码、新手机号及验证码。
- 服务端在单一业务库事务内锁定当前用户，校验当前绑定手机号、按稳定顺序消费两条验证码、锁定并检查新手机号唯一性后更新手机号。任一可恢复校验失败都会回滚验证码消费。
- 新旧手机号相同、非法手机号、错误或过期验证码、未登录、已被其他用户占用的新手机号均不可换绑；短信码、网关授权及用户凭据不出现在响应或日志中。

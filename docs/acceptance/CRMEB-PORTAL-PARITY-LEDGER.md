## 4. 生产级阻断项

1. `api-business` 仍有遗留 `api/internal/app`、`domain`、`persist` 模块引用旧 `qixi_m_*` 表；必须逐域迁至 `qixi_crm_b_*`。
2. 客服必须改为统一后台 JWT + RBAC/数据范围，并由 pte-live-im 按商户当前 SDK AppId 签发 UserSig；不能继续使用全局单 AppId 或旧服务入口。
3. 商户库到业务库的 store、商品、营销、直播、支付与 IM 配置投影必须经 outbox/NATS；不得由 C 端跨库读取。
4. 微信、支付宝真实预下单、异步回调验签、退款、对账尚未达到生产交付条件。
5. 所有端还缺同角色、同路径、同数据状态的 CRMEB 截图对照与浏览器回归证据。
6. 本地 Docker 集成环境未启动，因此数据库初始化、跨服务、NATS 投影、支付回调、IM 联调尚未形成闭环证据。

## 5. 关闭规则

每条 `docs/generated/features-master.tsv` 操作关闭时，必须补齐：

1. 参考路径与截图；
2. 七禧页面与提交路径；
3. Go handler / service / 表归属；
4. 后端权限、角色与数据范围拒绝测试；
5. 状态机、幂等或回归测试结果；
6. 结果截图和测试日期。

没有以上六项，状态只能是“迁移中”或“未完成”。

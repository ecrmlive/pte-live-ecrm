# H5 短信重置密码验收记录

日期：2026-08-04

## 已实现范围

- H5 密码登录页提供“忘记密码”入口，进入 `pages/login/reset-password`。
- 用户必须通过 `login_sms` 图形安全验证，才可为 `reset_password` 用途发送验证码。
- 验证码只保存手机号、用途和验证码的 SHA-256 摘要；有效期五分钟，同一手机号同一用途一分钟内不可重复发送，消费后不可再次使用。
- 用户输入手机号码、验证码和两次一致的至少 8 位新密码后，请求 `POST /api/app/v1/auth/password/reset`。
- 服务端锁定已绑定手机号的启用用户及其 H5 身份，更新 bcrypt 密码哈希并递增 `auth_version`，使先前访问令牌与刷新令牌失效。
- 对不存在手机号、禁用账户、无效或已消费验证码、密码不符合长度要求等情况返回受限错误；不回传验证码、短信网关授权或密码哈希。

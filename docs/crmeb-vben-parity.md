# CRMEB → 七禧 Vben 对齐验收

CRMEB 是功能和交互参考；七禧必须以 Vben 5.7+ 重实现，不复制或运行 CRMEB 后台代码。

## 目标前端边界

| CRMEB 入口 | 七禧目标 |
| --- | --- |
| `/admin/` 平台、区域、商户、客服、运营 | `admin-platform/`：一个 Vben 应用，通过角色、按钮权限和数据范围展示 |
| `/merchant/` 店铺 | `admin-merchant/`：独立 Vben 应用，包含店员/配送/服务人员角色 |

正式后台仅保留 `admin-platform`（平台、商户、区域、客服、运营角色）与 `admin-merchant`（店铺及员工角色）；不保留独立店员或客服项目。

## 单页完成条件

1. 对应角色可通过真实菜单进入 Vben 页面，禁止 placeholder。
2. 筛选、列表、分页、详情、表单、确认、错误和成功反馈与 CRMEB 同等。
3. 页面只调用真实 API，禁止 mock、假成功和空壳。
4. 统一后台校验角色、按钮权限与数据范围；店铺系统校验店铺范围和岗位权限。
5. 高风险域同时验收幂等、状态机和审计。
6. 保留同角色、同路径、同数据状态的 CRMEB 与七禧截图证据。

操作基线见 [CRMEB 全端功能验收总清单](./CRMEB-FULL-FUNCTION-CHECKLIST.md)。当前种子菜单已禁止回退到 placeholder：未知叶子会被隐藏而非伪装成已实现页面；但 CRMEB 全量目录、数据库、API 与运行时证据仍未完成迁移，因此不得宣称任何端已 100% 对齐或生产可用。

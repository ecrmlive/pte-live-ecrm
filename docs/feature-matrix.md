# 功能清单（功能表 + 脑图 + 源码对照）

原始图见 [`docs/assets/`](./assets/)。下列为结构化提炼，作为实现与验收基线。

## 1. 系统入口总览（脑图）

| 端 | 核心能力 |
| --- | --- |
| 用户端（H5 / 小程序 / App / PC） | 首页、分类、商品、购物车、结算、个人中心、营销活动、店铺街、分销、积分、社区、客服 |
| 平台后台 | 数据概览、商户管理、商品监管、订单/售后、财务结算、营销、RBAC、系统配置、DIY、素材 |
| 商户后台 | 店铺概览、商品/库存/规格、订单履约/核销、店铺营销、财务提现、店铺设置 |
| 商户手机端 | 商品上下架、接单发货、退款处理、经营数据 |
| 配送/服务人员端 | 配送接单、服务工单状态流转 |

## 2. 用户端功能

### 2.1 首页与基础商城

| 模块 | 功能点 | 说明 |
| --- | --- | --- |
| 首页 | 搜索、扫码、轮播、金刚区、公告 | 可配置导航与运营位 |
| 首页 | 秒杀/拼团/砍价/优惠券/直播入口 | 营销快速入口 |
| 首页 | 品牌店、店铺街、热销/精品/新品 | 多商户发现 |
| 分类 | 平台多级分类 + 筛选排序 | 销量/价格/新品/品牌/价格区间 |
| 商品 | 详情、多规格 SKU、视频、评价、收藏、分享海报 | 支持会员价/活动价 |
| 购物车 | 多商户分堆、改数量、结算 | 按商户拆单 |
| 结算 | 地址、运费模板、优惠券、积分抵扣、备注、支付方式 | 微信/支付宝/余额 |
| 订单 | 待付款→待发货→待收货→待评价→完成 | 取消、物流、核销、发票 |
| 售后 | 退款/退货、进度跟踪 | 全额或部分 |

### 2.2 店铺与入驻

| 模块 | 功能点 |
| --- | --- |
| 店铺街 / 店铺首页 | Logo、公告、店内搜索、店内商品、店铺优惠券、关注 |
| 商户入驻 | 在线申请、审核状态（待审/通过/拒绝）、短信通知 |

### 2.3 营销与增长

| 活动 | 要点 |
| --- | --- |
| 秒杀 | 场次、限时、限库存 |
| 拼团 | 成团人数、团进度、失败回退 |
| 砍价/助力 | 邀请助力降价 |
| 预售 | 全款 / 定金+尾款 |
| 优惠券 | 平台券 / 店铺券 / 商品券；领取与核销 |
| 积分商城 | 积分兑换 / 抵扣 |
| 分销 | 分销员等级、海报、团队、佣金与提现 |
| 会员 | 付费会员、权益、专属价 |
| 社区种草 | 图文/视频帖、关联商品 |
| 直播 | 直播间带货（小程序能力对齐参考实现） |

### 2.4 个人中心与资产

余额充值/账单、优惠券包、地址、发票、收藏店铺/商品、客服入口、设置（隐私/关于/帮助）。

### 2.5 客服与履约角色

- 用户 ↔ 商户/平台客服：文本、图片、表情；会话关联订单
- 配送员：接单、配送状态、确认送达
- 服务人员：预约/服务工单（待接单/进行中/完成）

## 7. 实现优先级建议

**P0（商城闭环）**  
商户入驻审核 → 商品/SKU/库存 → 购物车多商户拆单 → 支付 → 发货/核销 → 售后 → 商户结算提现 → 平台/商户 RBAC

**P1（运营增长）**  
优惠券、秒杀、拼团、积分、分销、会员、DIY 首页、素材库

**P2（扩展业态）**  
预售、砍价助力、卡密/虚拟商品、预约服务、同城配送员、社区种草、直播、打印机/电子面单

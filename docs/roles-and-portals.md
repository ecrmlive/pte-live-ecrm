# 角色与端入口

## 角色矩阵

| 角色 | 入口 | 数据范围 |
| --- | --- | --- |
| 平台超管/运营 | 平台后台（Vben） | 全平台 |
| 商户主账号/店员 | 商户后台（Vben）+ 商户手机端 | 本 `merchant_id` |
| C 端用户 | uni-app x / H5 / 小程序 / PC | 本人订单与资产 |
| 分销员 | C 端分销中心 | 本人团队与佣金 |
| 客服坐席 | 客服工作台 | 授权店铺会话 |
| 配送员 | 配送端 | 分配的配送单 |
| 服务人员 | 服务端 | 分配的服务工单 |

## 端与 API 前缀建议

| 端 | API 前缀 | 鉴权 |
| --- | --- | --- |
| 平台后台 | `/api/platform/v1` | 平台 JWT + RBAC |
| 商户后台 | `/api/merchant/v1` | 商户 JWT + 店铺权限 |
| C 端 | `/api/app/v1` | 用户 JWT |
| 开放接口 | `/api/open/v1` | AppKey / 签名 |
| 回调 | `/api/callback/v1` | 支付平台验签 |

## 页面信息架构（用户端）

对齐脑图与小程序 `pages`：

1. 首页 / 分类 / 购物车 / 用户
2. 商品详情 → 规格 → 下单
3. 订单列表/详情/售后
4. 店铺街 → 店铺首页
5. 营销活动页（秒杀/拼团/砍价/积分）
6. 分销中心 / 余额 / 优惠券
7. 客服会话
8. 商户入驻申请

## 管理端信息架构

### 平台

数据概览 → 商户 → 商品 → 订单 → 用户 → 营销 → 财务 → 配送 → 内容/DIY → 设置/权限

### 商户

店铺概览 → 商品 → 订单 → 营销 → 员工/客服 → 财务 → 店铺设置

## 权限原则

- 平台菜单与商户菜单两套 RBAC，不共用角色表主键空间（可同库不同表或 `scope` 字段）。
- 商户接口中间件强制注入并校验 `merchant_id`。
- 资金、退款、结算类操作写操作日志，关键操作可二次确认。

# 项目总览

## 定位

**qixi-live-mergers** 是多商户商城管理系统。功能基线对齐 CRMEB Merchant v4.0，技术栈按本仓库目标架构重建，不直接沿用 PHP/ThinkPHP/Swoole 运行时。

| 维度 | 说明 |
| --- | --- |
| 产品形态 | 平台运营 + 多商户入驻 + C 端商城 |
| 参考产品 | CRMEB 多商户系统 MER v4.0（`version=CRMEB-MER-v4.0`） |
| 本仓库角色 | 目标实现仓库（文档 / Skill / 后续源码） |
| 外部参考源码 | `~/Downloads/CRMEB多商户系统/CRMEB_MER_v4.0`（只读对照，不提交） |

## 系统组成

```text
统一后台管理系统(/admin) ── 平台 / 商户 / 区域 / 客服 / 运营五种角色
店铺管理系统(/merchant) ── 店铺经营、员工履约与店铺配置
PC、H5、小程序、iOS、Android、鸿蒙用户端 ── 浏览购买、营销活动、分销积分、客服售后
```

配送员、服务人员属于店铺系统角色；客服坐席属于统一后台角色；分销员属于 C 端角色。

## 建设原则

1. **功能对齐 CRMEB**：以功能表与源码模块为准，不做功能臆造。
2. **技术栈重建**：API 用 Gin + GORM + MySQL + etcd + NATS；管理后台 Vben 5+；C 端优先 uni-app x。
3. **高风险域隔离**：订单创建、支付回调、退款、库存、优惠券、积分、佣金、商户结算单独设计事务与幂等。
4. **本机构建、镜像挂载运行**：遵循 `unified-docker-release` / `docs/release/*`（代码落地后补齐）。
5. **任务边界**：收到开发/修改任务时只做方案、开发、查因、方案与修复；验证和部署由用户明确要求后再做。
